01 · Morse Code Lab

LIVE AUDIO

输入英文、数字或常见标点，点击播放收听摩尔斯电码。可调节发报速度与声音频率。

电码预览 / ENCODED MESSAGE

点击播放后，浏览器会使用设备扬声器输出声音。

02 · DTMF Tone Lab

DUAL-TONE

按下按键，体验无线电控制及电话系统常用的双音多频信号。A–D 为扩展 DTMF 按键。

LAST KEY—

每次点击会产生约 180 ms 的两种频率组合。此版本只在手机或电脑播放声音，不会向无线电发射。

03 · Parrot / Echo Test

规划中：回声录音与语音回放。普通 HTTP 内网页面通常无法获得手机麦克风权限，因此这一模块要先解决 HTTPS 或采用合适的本地音频方案。

目前尚未开放录音，不会请求麦克风权限。

04 · Raspberry Pi / SvxLink

规划中：显示真实的 SvxLink 服务状态、EchoLink 连接及音频接口测试。本网页目前属于独立离线模拟器，不代表已经与 SvxLink 连接。

部署到 Pi 后，可以继续添加受保护的本地控制接口。
